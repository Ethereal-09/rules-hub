# Quantumult X 懒人配置使用教程

> 本仓库提供的是**完整 QX 配置**，不是单条分流规则。导入会替换当前配置；先备份原配置，再操作。

## 1. 下载并导入

1. 复制配置直链：
   `https://raw.githubusercontent.com/Ethereal-09/rules-hub/main/Quantumult/dist/QuantumultX.conf`
2. 打开 Quantumult X，进入**配置文件**管理，选择**下载配置**，粘贴链接并确认。不同版本界面名称可能略有差异。
3. 如果直链访问失败，可使用[首页](../README.md#订阅地址) QX 表格里的 Boki 或 ghfast 加速链接下载；下载完成后检查配置能正常打开。
4. 切换到新配置，开启 QX，并确认运行模式为**规则分流**。导入后按需检查节点订阅和策略组选择。

## 2. 检查规则和重写

- 在 QX 的「分流规则」「重写规则」里更新远程资源，确认没有下载失败；本仓库仅镜像底包已启用且成功获取的功能依赖。
- 需要 HTTPS 重写功能时，在**自己的 QX 客户端**生成并安装 MitM 证书，再到 iOS 设置中信任该证书，开启 QX 的 MitM、重写开关；**不要导入别人提供的证书或私钥**。
- 图片或 App 数据异常时，查看 QX 网络活动的**具体命中规则与策略走向**，不要仅凭域名猜测是直连还是代理。

## 3. 更新与注意事项

GitHub Actions 每天构建并发布到同一地址；QX 下载配置后可重新获取主配置，远程规则仍依各自更新间隔在客户端更新。可查看 [构建记录](https://github.com/Ethereal-09/rules-hub/actions/workflows/quantumult.yml) 和 [镜像来源](SOURCES.md)。

配置源于 [ddgksf2013 底包](https://ddgksf2013.top/Profile/QuantumultX.conf)；本仓库保留其功能配置，并替换配置头、镜像启用的分流/重写及可识别脚本。**不会镜像节点订阅、证书与图标**；构建中下载失败的功能依赖会保留原上游链接。节点订阅请自行确认来源、有效性及隐私风险。
